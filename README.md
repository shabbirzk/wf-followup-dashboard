# Western Furniture Customer Follow-up Dashboard

## Requirements
- Node.js 18+
- MongoDB local or Atlas

## Run backend
```bash
cd server
copy .env.example .env
npm install
npm run dev
```

## Run frontend
Open another terminal:
```bash
cd client
npm install
npm start
```

Open http://localhost:3000

The API runs at http://localhost:5000. Update `server/.env` for MongoDB Atlas credentials.
